## 新增和改进的功能

| 功能 | 实际行为 | 主要修改位置 |
| --- | --- | --- |
| 增强SVD解析 | 安装硬件扩展后自动使用cmsis-svd 0.6，展开数组、分组和继承，并处理XML命名空间 | `ecdet/l3_analysis/hw_model/svd.py` |
| 位字段模型 | 保存字段名称、位偏移、位宽、访问权限和写入语义，计算可写的写1清零位掩码 | `ecdet/l3_analysis/hw_model/svd.py` |
| 写1清零风险规则 | 新增`ECDET-MMIO-W1C`，检查复合赋值、自增减和同一语句中的寄存器读回赋值 | `checks_hw.py`、`rules_meta.py` |
| 诊断接入修复 | 合并clang-tidy的stdout和stderr，支持Windows路径，去除重复诊断，超时保留部分诊断 | `ecdet/l3_analysis/adapters/clang_tidy.py` |
| 运行状态记录 | 记录外部工具缺失、超时、编译失败及SVD加载失败；基础解析遇到复杂描述会提示安装扩展 | `engine.py`、`context.py`及适配器 |

写1清零检查只在寄存器元数据明确时触发。`STATUS |= FLAG_A`可能将其他已置位状态一并读回并清除；直接写入待清除位的掩码不触发这条读改写规则。证据包含源码位置、寄存器地址、字段名称和写1清零位掩码，混合字段按实际写入语义核对。

## 安装和使用

在项目根目录执行：

```bash
python -m pip install -e ".[hardware]"
python -m ecdet scan examples/svd_enhanced_demo --no-build -o ecdet_reports/svd_enhanced
```

基础安装保持核心零第三方依赖，支持简单SVD及字段解析。数组、分组和继承使用硬件扩展；解析失败时日志明确记录MMIO检查跳过。

## 测试环境与证据

验证环境为Windows和Python 3.11。增强依赖位于`ecdet本地检查/reuse_audit_20261103/.venv/`，安装了cmsis-svd 0.6及pytest。

第一次默认环境全量测试出现14项动态相关失败，原因是Windows崩溃弹窗导致测试可执行文件被占用。已从修改前的HEAD导出独立基线复现同类错误；测试进程设置`SetErrorMode(3)`关闭崩溃弹窗后，基线对照测试和增强环境全量测试均通过。该设置保留崩溃退出结果，不改变检测断言。

Windows下复现全量测试的命令：

```powershell
python -c "import ctypes,pytest; ctypes.windll.kernel32.SetErrorMode(3); raise SystemExit(pytest.main(['-ra']))"
```

本次clang-tidy的执行状态和诊断转换通过模拟子进程验证；当前命令路径未发现可用的clang-tidy、Cppcheck和ESBMC，未运行这些工具的实际扫描。
