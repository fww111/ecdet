## 二、软件的主要功能（881 字，表单要求 500~1300 字）

```text
本软件面向嵌入式 C/C++ 工程，提供代码缺陷与安全漏洞的自动检测、告警研判与修复建议生成能力。主要功能如下：（1）编译环境复现：自动识别 Keil、IAR 等嵌入式工程结构，重建编译数据库并产出编译命令清单，为后续分析提供准确的编译上下文。（2）统一结果模型：将内置规则引擎与 cppcheck、clang-tidy、ESBMC 等外部引擎的输出统一转换为 SARIF 2.1.0 格式，形成单一结果数据模型。（3）静态检测：内置三十条规则，覆盖 MISRA C:2012 子集、CERT C 子集、通用缺陷规则与硬件语义规则；支持依据芯片描述文件校验寄存器读写权限，判定中断与任务共享变量的竞态与临界区缺失；通过抽象解释的常量传播证明数组下标越界，并按已证明、已检出、疑似三级标注可证明性。（4）动态检测：依据函数参数类型自动生成测试驱动，以特殊值与散列采样构造激励，在宿主或仿真环境执行被测函数，以崩溃退出码、未定义行为检测输出与看门狗超时判定缺陷，并生成可一键复现的概念验证样本。（5）告警分诊：对告警上下文进行裁剪后交由大模型研判，置信度不足时检索本地知识库重判，并核对引用的证据行，不可信结论降级为待复核；支持对接本地部署的兼容接口推理服务，数据不出域。（6）修复建议与验收：对确认缺陷生成函数级补丁，经静态重扫与编译器语法检查验证后输出统一差异补丁，未通过验证的补丁不予采纳；支持自动修复模式写入源文件并迭代收敛，给出验收扫描结果。（7）增量分析：按变更文件计算包含关系与调用关系的影响集，支持告警基线差分，输出新增、已解决、持续存在三态结果。（8）聚合与报告：告警去重聚合，建立 CWE、MISRA C、CERT C 与 GJB 8114 的映射关系，生成 SARIF 结果文件与单文件 HTML 检测报告。（9）Web 控制台：提供工程注册（本地路径、压缩包上传、Git 仓库三种来源）、扫描任务调度、源码浏览与告警定位、两次运行的版本对比、告警人工复核、一键修复与大模型端点配置等图形化操作，并自动保存每次运行的源码快照，便于回溯历史视图。
```
