## 六、改版重出方式

若需调整版本号、页码或内容，修改 `build/` 下对应脚本顶部的常量后重新执行：

```bash
uv run python 软著/build/gen_source_pdf.py   # 重出源程序 PDF
uv run python 软著/build/gen_manual.py       # 重出用户操作手册 PDF
uv run python 软著/build/gen_info_sheet.py   # 重出填写表并校验字数
```

三个脚本均依赖 `python-docx`、`pypdfium2`、`pillow`（已在开发依赖中），并通过本机 LibreOffice 完成 DOCX 到 PDF 的转换。
