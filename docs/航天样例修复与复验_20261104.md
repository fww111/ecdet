# Ecdet航天样例修复与复验报告

日期：2026年11月4日。检测器基线：`ec126667f6c91bad5623f9270c708e14473ace72`；GitHub航天样例：`61c9820a18416ccafd1a0073d60bd62a3fc848f2`。本PR包含检测器修改、回归测试和结构化复验数据。

## 结果

原4个样例的32个预置缺陷，检出数从1个增加到27个，检出率从3.125%提升到84.375%。355条已确认旧误报在当前重扫中全部消失。GitHub新增4个样例中，之前独立验证的3项漏报已补检2项，剩余1项为加热器占空比业务上限。

本次重扫覆盖8个原始工程和4个参考修复工程。原始样例的C源码、头文件及其他登记输入哈希与修复前一致。

|原始样例|修复前检出|修复后检出|剩余漏报编号|
|---|---:|---:|---|
|对地观测卫星|1/8|7/8|E02|
|深空探测器|0/8|7/8|D02|
|月球着陆器|0/8|7/8|L04|
|在轨服务航天器|0/8|6/8|O03、O04|

32个是缺陷实例数，其中4类通用缺陷分别出现在4个工程中；去掉这些重复设计后，共20种缺陷设计，本次检出15种。计数按文件、位置和根因匹配，同一缺陷的多个引擎告警只计一次。逐项结果见`review/seeded_defects.csv`。

## 修复内容

1. 修正格式化函数的格式串参数位置，区分固定字面量、未改写的固定字符串指针与可控输入。
2. 修正static函数、结构体字段、成员调用、函数指针、头文件声明和跨文件宏使用的识别，减少作用域和未声明类误报。
3. 修正嵌套分支、标签及无条件break的识别，区分数组使用与变长数组声明，避免把成员值或数组元素误当作指针转换。
4. 常量越界检查使用访问发生前的状态；存在未建模控制流时不输出Proven结论。
5. 临界区识别保留“进入后未退出”的配对告警，并识别未退出区间中的受保护访问；条件分支中的进入操作不能保护分支后的访问。
6. 增加结构体数组容量、复制长度、截断后的snprintf返回值、无符号回绕、符号重解释、分区跨界和释放后未清除字段指针的分析。新增`ECDET-CWE-119`、`ECDET-CWE-195`、`ECDET-CWE-416`，规则登记数由66增至69。
7. 持续副作用检查保留volatile读取、static局部状态修改和通过指针写入的告警；局部计算及只读函数不再仅因“发生调用”被判为持续副作用。

指针转换检查保留MISRA 11.3的字符类型访问例外，同时独立保留去除限定符检查。依据：[MISRA C:2012 Amendment 4，4.9](https://www.misra.org.uk/app/uploads/2023/03/MISRA-C-2012-AMD4.pdf)。

新增分析依赖`ecdet[syntax]`，采用ILP32标量范围模型，输出`Suspected`。它按局部路径与类型范围提示可能缺失的边界检查，复杂循环、跨函数业务状态和目标ABI需要进一步建模；源码审查或运行触发结果分别记录，不自动升级成形式化证明。

## 验证记录

- 12次最终扫描均生成SARIF和HTML报告，CodeChecker原生状态均为complete。每次扫描保存命令、退出码、输入哈希、编译数据库和原生日志；扫描期间及报告生成时检测器源码哈希一致。
- 32个原始缺陷触发全部失败，32个参考修复触发全部通过。失败依据为ASan/UBSan或具体业务断言，明细见`triggers/results.json`。
- GitHub新增3个探针重新运行：3个原版均触发失败，3个补防护的对照均通过。2个内存问题补防护后对应静态告警消失，见`remote_probes/static_pairs.json`。
- 首轮完整测试735项：713项通过、22项失败。失败包括宿主测试误用ARM交叉编译上下文，以及旧格式串断言。随后受影响模块131项测试剩8项失败，再修正测试编译环境、C语言方言、重复证据断言及符号转换误报后，相关62项全部通过。
- 最后新增并修正持续副作用边界案例，相关173项单元测试全部通过。按当前收集到的742个测试节点逐项汇总最近一次结果，均为通过；这是完整运行加定向复跑的合并结果。原始失败日志与各轮JUnit文件全部保留，见`review/test_verification.json`。

集成测试的原生编译设置只用于临时测试副本，仍实际调用CodeChecker。Web修复与分诊测试使用Mock模型，验证的是软件流程与约束执行。

本机ESBMC、Infer和CTU不可用；Z3对本批输入返回UNSUPPORTED。CLI退出码2对应这些未支持的验证状态，不当作“全部引擎验证通过”。主静态分析器成功及上述触发结果按各自证据记录。

## 剩余漏报与下一步

- 01_earth_observer/E02：姿态融合继续采用过期星敏感器数据。
- 02_deep_space_probe/D02：安全模式仍允许科学仪器上电。
- 03_lunar_lander/L04：单侧触地误信号触发提前关机。
- 04_orbital_servicer/O03：相对导航失联后仍沿旧数据接近。
- 04_orbital_servicer/O04：抓捕互锁漏检模式与闭合速度。
- EPS/R-EPS-01：加热器占空比最大800的业务约束。

这些问题需要把数据有效期、允许状态、触地判定和互锁条件写成工程约束，再接入检查与行为测试。当前已保留可复现探针及参考实现，后续可用同一批输入验证业务规则的检出效果。
